Add / Delete sequence of events

 

1. Overview

A sequence of events (a "string") is a resource that executes opportunities one after the other (see Sequence of events). Typical strings are:

•a drilling rig drilling new wells;

•a maintenance crew performing facility maintenance;

•a Well Services crew performing wellhead maintenance;

•a stimulation crew stimulating several wells;

•a construction team commissioning new facilities.

A scenario can hold up to 12 strings.

2. Open the "Sequence" window

1.Select the scenario on the main window.

2.Click "Sequence" in the "Expertise" group of the main ribbon, then "Add / Remove string. Modify string start date".

You can also double-click the name of a string (first column) on the timeline of the main window.

The window lists one row per string with three columns: "String Name", "Performed By" and "Start_Date".

Example: five strings (three rigs, a maintenance team and a construction team), each with its own start date.

3. Add, modify or delete a string

3.1 Add a string

1.Type the name in "String Name" on the empty last row (for example "Rig 4").

2.Enter the resource in "Performed By" (for example "Rig") and the date of the first opportunity in "Start_Date".

3.Click "Save" (or press Ctrl+S). Precept confirms "New sequences saved !" and closes the window.

The new string appears on the timeline, empty. Fill it with opportunities from the Pool (see Build sequence of events) or from Excel (see Build sequence from Excel).

3.2 Change a start date or a name

Edit "Start_Date", "String Name" or "Performed By" in the grid, then click "Save". Changing "Start_Date" moves every opportunity of the string by the same amount, so all the linked events (new wells online, shutdowns and constraints with relative dates) move with it.

3.3 Delete a string

1.Click a cell of the string to delete.

2.Click "Delete String" and confirm.

The string is deleted at once, its opportunities go back to the Pool, and the strings below it move up one position.

3.4 Change the display order ("Permute")

"Permute" swaps the position of two strings on the timeline, for example to show the rigs first, then maintenance, then construction. It does not change any date.

1.Click "Permute". The "Permute sequences" window opens (the "Sequence" window closes).

2.Select the first string in "Permute:" and the second in "With :".

3.Click "Permute". Precept confirms "New sequences saved !".

4. Result on the timeline

Once opportunities are added to the strings, the timeline of the main window shows the resulting schedule.

Schedule generated by the strings: each opportunity starts when the previous one in the same string ends.
