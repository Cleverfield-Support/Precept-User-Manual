Build sequence of events

 

1. Overview

Opportunities are scheduled by placing them in a string (see Sequence of events). The order is built directly on the timeline of the main window, with the mouse:

•Right-click acts like "Cut": the selected opportunities are removed from where they are.

•Double-click acts like "Paste": the cut opportunities are inserted before the opportunity you double-click.

When nothing has been cut, a double-click on an opportunity opens it for editing, and a double-click on the name of a string opens the "Sequence" window (see Add / Delete sequence of events).

2. The Pool of opportunities

A new opportunity is placed in the "Pool" of opportunities. Opportunities in the Pool are not executed in the forecast. The Pool is hidden by default: tick "Show Pool of Opportunities" at the top of the main window to show it.

Right-click the name cell (first column) of the Pool to hide it again. Right-clicking the name cell of a string hides that string from the timeline.

3. Move one opportunity

Example: move "Opportunity A" so that it is executed just before "Opportunity B".

1.Left-click "Opportunity A". It is highlighted in blue.

2.Right-click. "Opportunity A" disappears (it is cut).

3.Double-click "Opportunity B" (in the same string or in another one). "Opportunity A" is inserted just before "Opportunity B", and the dates of the string are recalculated.

To add the opportunity at the start or at the end of a string, double-click the empty cell at the start or at the end of that string.

4. Move several opportunities

1.Select all the opportunities to move (they are highlighted in blue).

2.Right-click. The selected opportunities disappear.

3.Double-click the opportunity before which they must be inserted. They are all inserted before it. Check the resulting order on the timeline.

5. Take an opportunity out of the schedule

1.Select the opportunity in its string and right-click it.

2.Double-click anywhere in the Pool. The opportunity is added at the end of the Pool and is no longer executed.

To schedule an opportunity from the Pool, select it in the Pool, right-click, then double-click the place where it goes in a string.

6. Change a duration

Use "Sequence" > "View sequence / Modify Opportunity duration" to type a new "Duration" or "End_Date", or "Sequence" > "Adjust Opportunity duration" to change it on the timeline. Every opportunity after it in the same string moves accordingly.
