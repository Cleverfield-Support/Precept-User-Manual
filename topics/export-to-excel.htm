Export to Excel

 

1. Exporting the forecast

The deterministic forecast of one or several scenarios can be exported to an Excel workbook (.xlsx).

1.Click "Export to Excel" in the "Forecast Results" group of the main ribbon. The "Export Forecast to Excel" window opens.

2.Choose the "Project :", then select the scenario(s) to export (Ctrl+click to select several).

3.Choose what to export in the node type list: "All Nodes", or a type ("Field", "Reporting", "Pattern", "Reservoir", or a node type of the network such as Well or Manifold) and then the node(s) in the list next to it.

4.Choose the reporting frequency: "Daily", "Monthly" or "Yearly".

5.Tick "Include historical data" to add the allocated history before the forecast.

6.Click "Export Forecast to Excel", choose the file name and location, and save. Precept confirms with "Forecast has been successfully exported !".

2. Content of the workbook

•One sheet per scenario, named after the scenario (its last 29 characters if the name is longer).

•At the top of each sheet: "Forecasted by Precept", the scenario name, and the start and end dates.

•Then one row per node and date, with the columns Scenario, Node, Type Node, Type Well, Reservoir, Date, then Liquid, Oil, Water, Gas, Gas-lift, Total Gas, Water Injection, Gas Injection, BSW, GOR, Production rb, Injection rb, Voidage, the matching cumulatives (Cum Liquid … Cum Voidage) and API.

•Column headers include the units of the asset (oilfield or metric).

Only the deterministic run is exported. To export a probabilistic Low, Mid or High case, first turn it into a scenario with "Generate Low Mid High cases" (see Probabilistic forecast). For a quick copy of a single chart's values, use "Forecast Data" in the Forecast Results window (see Forecast results: Charts).

3. Custom reporting

Cleverfield can also provide custom reporting in your own Excel format, or export the forecast results to a separate database. Contact Cleverfield support (support@cleverfield.fr) for more information.
