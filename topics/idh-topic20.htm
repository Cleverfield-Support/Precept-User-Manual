Precept Architecture

 

This chapter is the technical reference for IT teams and for anyone setting Precept up for the first time. Precept is a Windows desktop application: all calculations (forecast solver, decline curves, material balance) run on the user's PC, while inputs and results are stored in a central Precept database shared by all users of your company.

1. In this chapter

•Installation: prerequisites, installing Precept from the link provided by Cleverfield, first start-up and licence check, and how automatic updates work.

•Architecture: the components Precept connects to (licence, Precept database, production allocation database, optional external tools), the network ports to open, and access from reporting tools such as Power BI.

2. Related topics

•Security / Access policy: who can see an asset, create scenarios, edit decline curves or view results.

•Scenario Management: how assets, projects and scenarios are organised in the database, and how deleting scenarios keeps it small.
