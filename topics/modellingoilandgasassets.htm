Modelling oil and gas assets

 

This chapter explains how to build a forecast model of an asset in the Forecast module. The topics follow the order in which a model is usually built; most inputs are opened from the "Expertise" group of the main ribbon once a scenario is loaded. Start with Precept philosophy, which explains how potentials, the network and future events fit together.

1. Organise and protect the work

•Scenario Management: create the asset, a project and a scenario; duplicate, rename, share, lock, compare and delete scenarios.

•Security / Access policy: give colleagues access to the asset and set their permissions.

•Settings: units, time step, potentials method (decline curves, material balance or simulation) and the optional calculations of the scenario.

2. Wells and network

•Add wells to Asset Model: the wells of the asset and where each one flows.

•Network modelling: the production and injection network and its constraints, with Network editor, Network view and Network hydraulics.

•Patterns: pattern properties for voidage and recovery calculations per injection pattern.

3. Well potentials

•Decline curves: Decline curves: Production and Injection potentials, Duplicate / import profile, Analogues, Transient (potentials after a shutdown).

•New wells and changes of service: New profiles, Well conversion.

•Fluid properties: PVT.

•Physics-based potentials: Material Balance.

•Reservoir simulation: 3D model builder, Simulation coupling, and Experimental design studies on simulation decks.

4. Future events

•Opportunities: new wells, workovers, rig moves and other actions, with their profiles, durations and shutdowns.

•Sequence of events: the order in which rigs and crews perform the opportunities (Add / Delete sequence of events, Build sequence of events, Build sequence from Excel).

•Shutdowns: planned and unplanned shutdowns of wells and facilities.

•Constraints changes vs time: facility capacities that change during the forecast.

5. Economics, emissions and uncertainty

•Economical screener: OPEX and CAPEX, and the value of each opportunity.

•GHG emission: greenhouse-gas emissions and intensity.

•Probabilistic: input distributions and probabilistic forecasts.

6. Then run and analyse

When the inputs are in place, run the forecast (Forecast calculations) and analyse it (Forecast results). For a complete worked example, see the Tutorial.
