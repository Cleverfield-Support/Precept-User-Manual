Network view (forecast)

 

1. Overview

The network view shows the scenario's network next to the forecast results, month by month: which nodes are at a constraint, and the rates of any node or well. It is read only: the network is edited in the Network window (see Network editor).

2. Opening the view

1.Select the scenario in the main window and run its forecast (the view reads the saved results).

2.Tick "Show Network" in the main window. The "Network - <scenario>" window opens on the right half of the screen.

3.Untick "Show Network", or close the window, to close it.

While it loads, the status line at the bottom reads "Reading the forecast's constraints..." then "Reading the forecast dates...". If the scenario has no forecast yet, it says "No forecast for this scenario yet: run the forecast first."; if it has no network diagram, "No network diagram for this scenario."

3. The window

•Top: the month shown (e.g. "Mar 2027"), a date slider over every month of the forecast, and the "Wells" checkbox.

•Middle: the network diagram, fitted to the window. The legend in its top-left corner explains the red highlight: "Constrained".

•Bottom: the status line, which lists what is constrained in the month shown.

Maximise or resize the window to see more detail: the whole network is fitted again to the new size.

4. Constrained nodes, month by month

Move the slider to a month. Every node constrained during that month is framed in red, and the status line reads, for example: "Constrained in Mar 2027:  Platform A (liquid);   Compressor B (total gas)." followed by "Click a node or a well to see its rates." When nothing is constrained: "No network node constrained in <month>."

•The constraints come from the forecast's timeline: a node counts as constrained in a month when the forecast reported it constrained or at capacity on any day of that month. The fluid in brackets is the constrained phase; "process" means the forecast did not name one.

•Injection manifolds: when all the injectors of an injection node are fully open, the node is reported "constrained (all injectors at max choke)" and highlighted, even if no injection limit was entered on it. The injection is then limited by the injectors' potentials, not by a facility.

•Constrained wells: with "Wells" unticked they are only counted ("3 well(s) constrained too (tick Wells to see them)."); with "Wells" ticked they are highlighted and listed ("Wells constrained: …").

5. Wells

Tick "Wells" to draw each well under the node it flows to (or is injected from), linked by a line in its fluid colour: green oil producer, red gas producer, navy water injector, dark red gas injector. The diagram is fitted again to include them.

6. Rates chart of a node or a well

Click a node (or a well, when "Wells" is ticked). A small chart window opens, titled "<node> - <phase>". Clicking another node shows that node in the same window.

•The rate of the phase is drawn as a coloured area, with the constraint set on the node as a dotted "Constraint" step line (for "Pressure": "Min pressure" and "Max pressure").

•The month selected with the slider is marked by a blue dashed vertical line, which follows the slider.

•The first list picks the phase: Oil, Water, Gas, Liquid, BSW, GOR, Gas-lift, Total Gas, Water Injection, Gas Injection, Pressure.

•The second list picks the frequency: "Monthly" (default), "Quaterly" or "Yearly".

The phase shown first is chosen for you, in this order:

1.the phase constraining the node in the month shown;

2.else a constraint set on the node in the initial constraints (preferring one that was reached during the forecast) — for example a compressor's Total Gas;

3.else the phase the node was most often constrained on during the forecast;

4.else the first phase that flows through it, among oil, water injection, gas injection, gas and liquid.

The rates and constraint lines are the same as in the Results charts (see Forecast results: Charts). Constraints that change with time (see Constraints changes vs time) show as steps of the dotted line. For a Material Balance or Simulation scenario, "Pressure" shows the node pressure solved by the network (see Pipelines, pumps and network pressure solve).
