Build sequence from Excel

 

1. Overview

The order of a string (for example a drilling schedule for "Rig 1") can be pasted from Excel instead of being built with the mouse. The pasted list replaces the whole order of that string. The string itself must exist first (see Add / Delete sequence of events), and the opportunities must already exist (see Opportunities).

2. Prepare the list in Excel

Use two columns: the order (starting at 1) and the exact name of the opportunity. A header row starting with "Order" (or "Rank") is ignored when pasted.

3. Import the list

1.Click "Sequence" in the "Expertise" group of the main ribbon, then "Import schedule from Excel".

2.In the drop-down at the top left (it shows "Select sequence"), select the string to fill (for example "Rig 1").

3.Copy the two columns in Excel, click the grid and press Ctrl+V.

4.Check the list, then click "Save sequence order". Precept confirms "New sequence successfully saved." and closes the window.

The "Import schedule from Excel" window after pasting four opportunities into a string.

Precept keeps the order of the pasted rows. The opportunities listed are executed one after the other from the start date of the string; any opportunity of that string that is not in the list goes back to the Pool. If the grid is empty, Precept shows "The sequence is empty." and nothing is saved.
