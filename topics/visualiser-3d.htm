3D visualiser — reservoir grids, results and the network

 

1. Overview

The 3D visualiser displays a reservoir simulation grid in 3D. You can colour it by a static property or by a simulated result at each report step, slice it, filter it, and inspect any cell. A plan-view map and a cross-section are shown beside the 3D view. The wells of the model are drawn, and when the viewer is opened from a scenario, that scenario's production network can be drawn above the grid.

The visualiser is for viewing only: it never changes anything in the Precept database.

2. Opening it

2.1 From a scenario — "3D model visualization"

1.Select the scenario in the main window.

2.Click "3D model visualization" in the "3D Modelling" group of the main ribbon. The group is shown when "3D Simulation model" is ticked in Settings, under "Pre / Post Processing".

3.The latest simulation run of the scenario is loaded automatically: the grid, its static properties and its results. If the scenario has not been simulated yet, Precept says "No simulation grid (…EGRID) was found for this scenario" — run the simulation first from the 3D model builder (see Simulation).

Opened this way, the viewer knows the scenario, so the "Network" option can draw its production network. Grids built with the 3D model builder are shown with north up.

2.2 From a file — "3D Model Visualiser"

1.In the Field Monitoring window, click "3D Model Visualiser". The viewer opens empty.

2.Click "Load model" and choose a grid file: .EGRID, .GRDECL or .GRID.

3.If static properties (.INIT) or dynamic results (.UNRST) with the same name sit next to the grid file, Precept asks "Load them too ?". Answer Yes to colour the grid by them.

A "Loading 3D model" progress window follows the load; click its "Cancel" button to stop. The viewer needs the Microsoft Edge WebView2 runtime, which is normally present on Windows. If it is missing, Precept reports "WebView2 runtime missing or failed to start".

3. The screen

Figure 1 — Layout of the 3D visualiser window.

•Top left: the model name, its size (NX x NY x NZ), the number of active cells, report steps and wells, and the last picked cell.

•3D view: the grid, with a compass and a colour bar. Type new values in the boxes above and below the colour bar to change the colour scale; "Auto" restores it and "invert" reverses the colours.

•Right-hand side: "Map (plan view) — top visible layer" and "Cross-section".

•Bottom: the control panel (section 5).

4. Navigating

Where

Mouse

3D view

Left-drag: rotate. Right-drag: pan. Wheel: zoom. Right-click on a cell without moving the mouse: show the cell's I, J, K and property values.

Map (plan view)

Drag: draw the slice line used by the cross-section. Wheel: zoom. Shift-drag: pan. Double-click: reset the view. Right-click: cell value.

Cross-section

Wheel: zoom. Ctrl+wheel: stretch the depth axis. Drag: pan. Double-click: reset. Right-click: cell value.

5. The control panel

Control

What it does

Property list

The property used to colour the grid. Static properties come from the grid or the .INIT file: porosity, permeabilities, net-to-gross, depth, initial water saturation and pore volume, when present. Dynamic results come from the .UNRST file: pressure, water saturation and gas saturation.

"► Play" / "Pause" and "Time step"

Step through the report steps of a dynamic result, automatically or with the slider.

"Slice plane", "Slice azimuth (°)", "Slice position"

Cut the grid with a vertical plane, set its direction and move it across the model.

"Slice I / J / K"

Show a single row, column or layer of cells ("Off", "I", "J" or "K", then the slider).

"I / J / K range"

Keep only a box of cells (min and max I, J and K). "Reset" restores the full grid.

"Filter (current property)"

Keep only the cells whose value is between "min" and "max". "Clear" removes the filter. "Stats" shows statistics and a histogram of the property, for all cells and for the filtered cells.

"Vertical exaggeration"

Stretch the depth axis of the 3D view.

"Wells"

Show or hide the wells.

"Network", "Equipment", "Sea surface"

Show the scenario's production network above the grid, its process equipment (compressors, pumps, flares…) as separate nodes, and the sea surface.

"Gridlines"

Draw the cell edges.

5.1 Wells and cross-sections along a well

Wells are read from the simulation results (.UNRST): each well is drawn through its completed cells, labelled with its name and coloured by type (producer, water injector or gas injector). In the "Section :" list above the cross-section, choose "Straight (slice line)" to follow the line drawn on the map, or "Along <well>" to follow a well's completions.

6. Data needed

To see

You need

The grid

A grid file: .EGRID (written by the simulator), .GRDECL or .GRID.

Static properties

The .INIT file of the run, or properties stored in the .GRDECL file.

Results and wells

The .UNRST (unified restart) file of the run. Without it, the grid shows no time steps and no wells.

The network overlay

Opening the viewer from a scenario ("3D model visualization"), and map coordinates (X and Y) for at least two of its wells in the network model, so that the network can be positioned on the grid. Nodes without coordinates are not drawn. Node elevations (the Z column of the network's coordinates grid, in TVDSS) place platforms and risers above the seabed. See Network modelling.

Well trajectories entered in Precept are not used by the 3D visualiser: the wells come from the simulation model itself.

7. Exporting images

Click "Export image" on the ribbon. In the "Export image" window, tick what to save — "3D view (with compass + colour bar)", "Map (plan view)", "Cross-section" — and choose the resolution (1x, 2x or 4x), then click "Save ...". One image is saved through a save dialog; several are written to a folder you choose. Images are saved as PNG files.
